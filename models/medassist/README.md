# MedAssist ML research

This directory contains the offline English-only, open-access research specification. It does not configure the running application or enable clinical inference.

- [Verified dataset manifest](open-access-manifest.json): pinned sources, access/terms, target codes, published marginals, permitted feature profiles and acquisition receipts still needed.
- [Technical experiment plan](experiment-plan.md): separate NHAMCS recorded-acuity and DDXPlus conversation experiments, leakage controls, model comparisons and evaluation gates.

No row-level dataset, trained model, checkpoint or new inference integration was produced by this planning task. Full credentialed MIMIC datasets are excluded. Open access does not remove licensing, confidentiality, attribution or intended-use limits.

Use the [main research register](../../docs/research-and-validation.md) for broader evidence governance and the [roadmap](../../docs/roadmap.md) for work sequence. The next implementation is acquisition/profiling only, after a separate user-authorized task.
