# Product layer guides

These pages describe intended behavior and acceptance criteria. The existing application remains a design demo; none of these guides claims a completed product layer.

- [MedAssist AI](medassist.md): conversation, reviewed care guidance, ML research, and facility navigation.
- [ADR reporting](adr-reporting.md): direct intake, confirmation, cases, reports, sharing, and follow-up.
- [Professional intelligence](professional-intelligence.md): review, evidence, statistics, and authorized outputs.
- [Agent orchestration](agent-orchestration.md): Reporting, Validation, Knowledge, and Analysis coordination.

MedAssist and ADR reporting are the two product layers; professional intelligence is part of the ADR layer, and orchestration connects supported functions across them.

A layer change must update its guide, any affected architecture/data contracts, the [roadmap](../roadmap.md), and [dated history](../history/README.md) as applicable. Keep shared mission and team information in [product](../product.md) rather than repeating it here.
