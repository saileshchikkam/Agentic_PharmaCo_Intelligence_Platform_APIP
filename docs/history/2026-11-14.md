# Development history — 2026-11-14

## MedAssist v2 conversational UI integration, canonical routing, and assessment restoration

Integrated and showcased Jayanth's merged MedAssist v2 conversational experience (PR #17) into the active APIP integration branch (`codex/apip-landing-v2`).

### Motivation and Scope
Previously, while Jayanth's MedAssist v2 contributions were merged into `origin/main` (commit `2cc9ce5abe4f2cf63ebbffd9f1a707cc7821d710`), the active integration branch `codex/apip-landing-v2` continued displaying the legacy static MedAssist preview by default, with the conversational component locked behind an `import.meta.env.DEV` check. This task restored the conversational experience as the primary MedAssist interface for the final demo preview while preserving platform security, ADR workflow independence, and data isolation.

### Key Changes
- **Canonical Routing & Entry Point (`src/features/access/AccessPreview.tsx`)**:
  - Removed `import.meta.env.DEV` conditional import; `MedAssistConversation` is now imported unconditionally via `React.lazy()`.
  - Mapped canonical routes `#/preview/medassist` and `#/preview/medassist-conversation` to `{ screen: 'medassist-conversation' }`.
  - Mapped legacy mock preview to `#/preview/medassist-legacy` for reference.
  - Simplified the Patient Dashboard MedAssist task card: clicking "Explore MedAssist" navigates directly to the conversational experience (`#/preview/medassist`). Removed the redundant development-only button.
  - Unlocked public preview access to `medassist-conversation` without triggering forced redirect to patient login dialog, while preserving session return path handling.
- **Conversational Header (`src/features/medassist-conversation/MedAssistConversation.tsx`)**:
  - Upgraded header hierarchy: Title ("MedAssist AI"), Subtitle ("Conversational Symptom Understanding — Research Preview"), and dual status badges:
    - Research Mode badge: `Scripted research demo` (when running client-side simulation) or `Model A research connected` / `Model A research unavailable`.
    - Status badge: `Urgency not assessed`.
  - Added primary header action buttons: `Restart` (restarts fictional session) and `Emergency help` (triggers immediate emergency escalation).
  - Expanded `<details><summary>Demo scope and privacy</summary>` disclosure: explicitly documented bounded 9-field symptom scope, explicit user confirmation requirement, separation of unmapped descriptions, Model A simulation/connection state, unavailable Model B urgency, absence of clinical diagnosis/prescriptions, and link to Developer research lab (`#/research/model-a`).
- **Four-Level Urgency Assessment Panel (`src/features/medassist-conversation/MedAssistConversation.tsx`, `conversation.css`)**:
  - Restored the structured 4-level urgency status panel alongside the conversational workspace:
    - Low (Green `#34a853` dot, Routine symptoms, pill: "Not assessed")
    - Moderate (Yellow `#fbbc05` dot, Needs monitoring, pill: "Not assessed")
    - High (Orange `#f97316` dot, Prompt review, pill: "Not assessed")
    - Very High (Red `#ea4335` dot, Urgent attention, pill: "Not assessed")
  - Guaranteed truthful disclosure: all 4 category cards remain neutral and unselected with explicit explanation: *"Four-level urgency assessment is planned. No validated severity classification is currently available in this research preview."*
  - Added real-time session research summary block tracking: Research Mode, Questions Answered count, Confirmed Symptoms count, Additional Descriptions count, Model A status, and Safety Guard active indicator.
  - Added prominent emergency guard alert when safety triggers: *"Emergency statement guard triggered. Urgent medical consultation advised. Call 112 in India."*
- **Layout & Responsive Polish (`src/features/medassist-conversation/conversation.css`)**:
  - Desktop layout balanced to ~68% conversational timeline and ~32% assessment panel via `grid-template-columns: minmax(0, 1fr) 320px; gap: 24px;`.
  - Clean Material Design 3 cards with subtle outlines (`--md-sys-color-outline-variant`), 12px card radii, and 20px sidebar radius.
  - Smooth responsive behavior: below 1000px, switches to a stacked vertical layout with collapsible assessment details; refined mobile composer padding and font scaling.
- **Language Context & Pain Scope Boundary Fix (`pain-scope.ts`, `language-context.ts`)**:
  - Added punctuation trimming to `hasPainException()` to ensure robust regex matching on trailing punctuation.
  - Protected pain exception clauses from aggressive clause-splitting in `language-context.ts`, ensuring complex exceptions (e.g. "No pain except perhaps the head") correctly evaluate to unasserted / ambiguous rather than unqualified negative claims.
- **Test Alignment (`scripts/medassist-conversation.test.ts`)**:
  - Updated test assertions to verify canonical routing (`path === '/preview/medassist'`), "Explore MedAssist" entry point, and updated CSS grid template columns.
